## 📊 Análisis de Mercado Argentino

### Competidores Directos (Software de Gestión en Argentina)

| Competidor | Plan Básico | Plan Medio | Premium | Notas |
|------------|-------------|------------|---------|-------|
| **SaaS Argentina** | GRATIS | $61,180/mes + IVA | N/A | Facturación + gestión general |
| **Tango ERP** | $15,000/mes | Variable | Variable | Por módulos, muy genérico |

### Referencia de Precios del Mercado
- **Básico:** $3,000 - $20,000 ARS/mes
- **Medio:** $15,000 - $35,000 ARS/mes
- **Premium:** $55,000 - $65,000+ ARS/mes

### Contexto Económico
- **Dólar Blue:** ~$1,185 ARS (abril 2025)
- **Inflación:** Alta → Necesitas ajustar precios periódicamente
- **Recomendación:** Precios en ARS pero con revisión trimestral
- **Alternativa:** Indexar a algún índice (IPC) o dólar para estabilidad

Queremos que sea **accesible para cualquier florería argentina**, desde la chica que trabaja sola hasta la que tiene 3 sucursales.

**Proporción recomendada: 1 : 4 : 9**
(El plan del medio es 4× el gratis, el enterprise es ~2× el medio)

## 📊 Métricas a Monitorear

### Key Performance Indicators

1. **Conversion Rate por Plan**
   - Target: 60-70% elige Profesional
   - <40% = ajustar precios/features
   - >80% = podrías cobrar más

2. **Churn Rate (Cancelaciones)**
   - Target: <5% mensual
   - Si >10% = problema de valor/precio

3. **Free → Paid Conversion**
   - Target: 20-25% convierten en 90 días
   - Si <10% = plan gratis muy generoso o paid muy caro

4. **Monthly Recurring Revenue (MRR)**
   - Crecimiento mes a mes
   - MRR = Σ(suscripciones activas × precio)

5. **Customer Lifetime Value (LTV)**
   - Target: LTV > 3× CAC (costo adquisición)
   - LTV = (ingreso mensual promedio) / churn rate

## 🔧 Implementación Técnica

### Backend Changes Necesarios

1. **Base de Datos:**
```sql
-- Tabla de planes
CREATE TABLE subscription_plans (
  id UUID PRIMARY KEY,
  name VARCHAR(50), -- 'semilla', 'florecer', 'crecimiento', 'jardin'
  price_monthly DECIMAL(10,2),
  price_annually DECIMAL(10,2),
  max_users INT,
  max_orders_per_month INT, -- NULL = ilimitado
  features JSONB,
  created_at TIMESTAMP
);

-- Tabla de suscripciones
CREATE TABLE subscriptions (
  id UUID PRIMARY KEY,
  tenant_id UUID REFERENCES tenants(id),
  plan_id UUID REFERENCES subscription_plans(id),
  status VARCHAR(20), -- 'active', 'cancelled', 'past_due', 'trial'
  billing_cycle VARCHAR(20), -- 'monthly', 'annually'
  current_period_start DATE,
  current_period_end DATE,
  cancel_at_period_end BOOLEAN,
  created_at TIMESTAMP
);

-- Tabla de usage tracking
CREATE TABLE subscription_usage (
  tenant_id UUID,
  month DATE,
  orders_count INT,
  users_count INT,
  created_at TIMESTAMP
);
```

2. **API Endpoints:**
```
GET    /api/subscription/plans           # Lista todos los planes
GET    /api/subscription/current         # Plan actual del tenant
POST   /api/subscription/upgrade         # Upgrade de plan
POST   /api/subscription/downgrade       # Downgrade (efectivo al final del período)
POST   /api/subscription/cancel          # Cancelar (acceso hasta fin del período)
GET    /api/subscription/usage           # Uso actual vs límites
POST   /api/subscription/webhook         # Webhook de Stripe/payment processor
```

3. **Middleware de Feature Flags:**
```javascript
// Verificar límites del plan antes de acciones
const checkPlanLimits = (requiredFeature) => {
  return (req, res, next) => {
    const tenant = req.tenant;
    if (!tenant.subscription.features.includes(requiredFeature)) {
      return res.status(403).json({
        error: 'Feature not available in your plan',
        upgradeRequired: true,
        suggestedPlan: 'florecer'
      });
    }
    next();
  };
};
```

4. **Integración de Pagos:**
   - **Recomendado para Argentina: MercadoPago** (local, acepta todo, fácil integración)
   - **MercadoPago SDK:** Checkout Pro (redirect) o Checkout Bricks (embedded)
   - **Suscripciones automáticas:** MercadoPago tiene "suscripciones" nativas
   - Alternativa internacional: Stripe (pero requiere empresa fuera de Argentina)
   - **IMPORTANTE:** Configurar webhooks para sincronizar pagos automáticamente
   
   **Opciones de pago a ofrecer:**
   - ✅ Tarjeta de crédito/débito (vía MercadoPago)
   - ✅ Transferencia bancaria (CBU/CVU)
   - ✅ MercadoPago wallet
   - ✅ Efectivo en Rapipago/Pago Fácil (pero genera más churn)

## 💡 Recomendaciones Finales

### ✅ Hacer
- Empezar con precios FUNDADOR más bajos ($12,000/$24,000)
- Lock de precio por 12 meses para early adopters
- Incluir onboarding GRATIS en plan pago
- 14 días de prueba en planes pago
- Hacer el plan del medio OBVIAMENTE el mejor deal
- Mostrar Enterprise primero como ancla de precio
- Usar **MercadoPago** para pagos (es el estándar en Argentina)
- Incluir facturación AFIP como feature clave
- **Revisar precios trimestralmente** por inflación
- Considerar ofrecer descuento por pago anual anticipado

### ❌ NO Hacer
- No cobrar setup fee obligatorio (crea fricción)
- No hacer plan gratis demasiado generoso
- No poner demasiados planes (máx 4)
- No esconder el precio (transparencia = confianza)
- No hacer contratos largos (month-to-month al inicio)
- **NO fijar precios en USD** (genera desconfianza local)
- No ignorar la inflación (ajustar con IPC o criterio propio)

### 🎯 La Regla de Oro
**"El plan del medio debe sentirse como un no-brainer"**

Cuando alguien vea los 4 planes, debe pensar:
> "El gratis es muy limitado, el enterprise es demasiado para mí... 
>  el Profesional es perfecto para lo que necesito."

### 📌 Manejo de Inflación (Crítico en Argentina)

**Opción A: Ajuste Trimestral (Recomendada)**
- Cada 3 meses, revisar precios para NUEVOS clientes
- Clientes activos mantienen precio por 6 meses
- Comunicar con 30 días de anticipación
- Mensaje: "Ajuste por condiciones económicas"

**Opción B: Plan Anual como Hedge**
- Incentivar pago anual con descuento fuerte
- "Pagá $180,000 hoy y congelá el precio por 12 meses"
- Te da cash flow y al cliente le conviene

**Opción C: Indexación Transparente**
- Precios atados a algún índice (ej: IPC INDEC)
- Automático, sin negociaciones
- "Nuestros precios se ajustan igual que tu negocio"

**Mejor approach inicial:**
- Primeros 6 meses: precios congelados
- Después: ajuste discrecional (10-15% si la inflación lo justifica)
- Siempre avisar con 30 días
